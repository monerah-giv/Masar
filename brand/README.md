# هوية مسار

**الفكرة:** كلمة «مسار» مرسومة كخط مترو بخط واحد متصل، بزوايا 0° و45° و90° فقط.

- **م:** حلقة محطة فيها نقطة ذهبية تعني الوصول. وهي أيضاً أول حرف في «مترو».
- **س:** ثلاث علامات محطات على الخط.
- **ا:** صاري عمودي.
- **ر:** تفرّع بزاوية 45°.

**الأيقونة:** الحلقة نفسها عند نقطة تحويل. ساق بيضاء ترتفع، ثم تتحول عند الحلقة، ثم تخرج ساقاً ذهبية. الرسالة: «اركب، حوّل، اصل».

## القواعد

| | |
|---|---|
| نصف قطر الحلقة | 1.43 × سماكة الخط |
| النقطة الذهبية | 0.42 × نصف القطر |
| الأطراف والوصلات | دائرية |
| مساحة الأمان | قطر الحلقة من كل جهة |

## الألوان

| الاسم | فاتح | داكن | الاستخدام |
|---|---|---|---|
| أخضر مسار | `#00795C` | `#34C495` | اللون الأساسي، الأزرار، الأرقام الكبيرة |
| ذهبي الوصول | `#F6B53C` | `#FFC65A` | نقطة الوصول، التذكرة، مؤشر التبويب. يُستخدم بقلّة |
| ليل نجد | `#0B1A22` | — | النصوص، خلفية الوضع الداكن |
| ضباب | `#EEF3F1` | — | خلفية التطبيق |

ألوان المسارات الستة تمثّل بيانات وليست جزءاً من الهوية، فلا تُستخدم للزينة.

## الملفات

- `svg/`: الأصول المتجهية.
  - `masar-icon*.svg`: الأيقونة بأنواعها: فاتحة، وداكنة، وملوّنة بلون النظام، وليلية.
  - `masar-wordmark*.svg`: الكلمة بثلاثة ألوان.
- `png/`: الأيقونات بمقاس 1024 جاهزة لـ Xcode، والكلمة بخلفية شفافة.
- `src/geo.py`: المصدر الهندسي الوحيد. أي تعديل في النسب يتم هنا، ثم يُعاد التوليد:

```bash
cd brand/src && python3 -c "from geo import *; print(icon_svg('light'))"
```

في التطبيق تُرسم العلامات متجهياً من الأبعاد نفسها:

- iOS: `ios/Masar/Support/Brand.swift`، وفيه `MasarWordmark` و`MasarSymbol` و`RouteRibbon`.
- الويب: `web/app.html`.
