# لوحة التحكم / Admin control page

**الرابط:** `https://masar.sa/admin/`

الرابط غير ظاهر في التطبيق، ومحجوب عن محركات البحث. ومعرفته وحدها لا تكفي للدخول.

## من يدخل؟
لا يدخل إلا من تتحقق فيه ثلاثة شروط معاً:
1. **مفتاح GitHub** صالح وفيه صلاحية الكتابة على المستودع.
2. أن يكون صاحب المفتاح ضمن قائمة `admins` في `data/app.json`، وفيها حالياً `monerah-giv`.
3. **عبارة مرور السجل المالي**: من دونها لا يمكن قراءة بيانات المعلنين والمدفوعات.

### إنشاء المفتاح (مرة واحدة)
1. افتح GitHub ← **Settings** ← **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. **Repository access**: اختر *Only select repositories* ثم **Masar**.
3. **Permissions** ← **Contents**: اختر *Read and write*. لا تضف أي صلاحية أخرى.
4. اختر مدة انتهاء، مثلاً 90 يوماً، ثم انسخ المفتاح والصقه في صفحة الدخول.

إذا تسرّب المفتاح، احذفه من الصفحة نفسها في GitHub. يتوقف عمله فوراً.

خيار «تذكّر المفتاح على هذا الجهاز» يحفظ المفتاح في متصفح ذلك الجهاز. لا تفعّليه إلا على جهازك الشخصي. ومن دون هذا الخيار يُمحى المفتاح عند إغلاق التبويب.

### عبارة المرور
تُطلب عند أول دخول، وبها يُشفَّر السجل المالي `data/billing.enc`:
- التشفير AES-256-GCM.
- المفتاح يُشتق من العبارة بـ PBKDF2-SHA256 مع 310,000 تكرار.

المستودع عام، لكنه لا يحوي إلا نصاً مشفّراً. **لا يمكن استرجاع السجل إذا ضاعت العبارة**، فاحفظيها في مدير كلمات مرور.

## ماذا تفعل اللوحة؟
| | |
|---|---|
| **الملخص** | المحصَّل هذا الشهر والإجمالي، المتبقي على المعلنين، المتأخرات المستحقة الآن، الإعلانات الظاهرة، المخفية لعدم الدفع، نسبة إشغال المساحات |
| **حجز جديد** | بيانات المعلن والإعلان بالعربية والإنجليزية، والمحطة أو المسار أو الشبكة، والمدة. السعر يُحسب من جدول الأسعار، أو يُكتب سعر متفق عليه. خطة الدفع: كامل أو أسبوعي أو شهري. اللوحة ترفض أي حجز يتجاوز المساحات المتاحة |
| **تسجيل دفعة** | المبلغ والتاريخ والطريقة (تحويل، مدى، STC Pay، رابط دفع، نقداً) والمرجع. يظهر لك قبل الحفظ التاريخ الذي سيبقى الإعلان ظاهراً حتى نهايته |
| **تذكير واتساب** | رسالة جاهزة بالقسط المستحق وتاريخه، ومعها رابط الدفع إن وُجد |
| **إيقاف واستئناف** | إخفاء الإعلان يدوياً لأي سبب، مع بقاء الحجز |
| **إلغاء الحجز** | يختفي الإعلان وتتحرر المساحة، ويبقى سجله المالي |
| **المدفوعات** | سجل كامل للمدفوعات مع تصدير CSV للمحاسبة |
| **الأسعار والإعدادات** | أسعار الفئات A وB وC، وعدد المساحات في كل محطة، وأيام السماح، ووسيلة استقبال طلبات المعلنين |

لا يصل أي تغيير إلى التطبيق قبل أن تضغطي **«نشر للتطبيق»**. عندها يُحفظ الملفان (`ads.json` و`billing.enc`) في عملية حفظ واحدة على GitHub، ثم يُنشر الموقع آلياً خلال دقيقة إلى دقيقتين.

## كيف يُخفى الإعلان غير المدفوع؟
**المال يشتري أياماً.** كل حجز له إجمالي، وكل ريال مدفوع يغطي حصته من أيام الحجز بدءاً من تاريخ البدء.

مثال: حجز 28 يوماً إجماليه 4,968 ريالاً. إذا دُفع ربع المبلغ، أي 1,242 ريالاً، يغطي ذلك أول 7 أيام.

تكتب اللوحة آخر يوم مغطّى في الحقل العام `paidUntil`، والتطبيقان يقارنان التاريخ بنفسيهما:
- **يظهر الإعلان** من تاريخ البدء حتى `paidUntil`، ويُضاف إليها `graceDays` (أيام السماح، والافتراضي 0).
- **في اليوم التالي يختفي تلقائياً** من الموقع ومن تطبيق iPhone، دون أي تدخل ولا إعادة نشر.
- **يعود فور تسجيل الدفعة ونشرها.**
- الحجز الذي لم يُدفع منه شيء لا يظهر أبداً، والموقوف لا يظهر مهما كانت دفعاته.

الحالات في اللوحة:

| الحالة | معناها |
|---|---|
| **نشط — مدفوع** | الإعلان ظاهر للركاب |
| **يستحق قريباً** | تنتهي الأيام المدفوعة خلال 3 أيام أو أقل |
| **متأخر — مخفي** | الإعلان مخفي لعدم الدفع |
| **بانتظار الدفعة الأولى** | لم يبدأ الحجز، ولم يُدفع منه شيء |
| **مجدول — مدفوع** | لم يبدأ الحجز، وأول أيامه مدفوعة |
| **موقوف** | أُخفي يدوياً |
| **منتهٍ** | انتهت مدة الحجز |
| **منتهٍ — عليه مستحقات** | انتهت المدة وبقي على المعلن مبلغ |
| **ملغى** | أُلغي الحجز وتحررت مساحته |

## الدفع الإلكتروني
يمكن وضع رابط دفع من بوابتك، مثل ميسّر أو تاب أو PayTabs، لكل حجز، فيُرسل مع التذكير.

تأكيد الدفع **يدوي**: تسجّلين الدفعة بعد وصولها. التأكيد الآلي يحتاج خادماً صغيراً يستقبل إشعارات البوابة (webhook)، ويمكن إضافته لاحقاً دون تغيير هذه القواعد.

## ما يبقى عاماً وما يبقى خاصاً
| عام: يراه الركاب ومن يقرأ المستودع (`data/ads.json`) | خاص: مشفّر (`data/billing.enc`) |
|---|---|
| اسم النشاط والعرض والرابط وهاتف النشاط وموقعه | اسم المعلن وجواله وبريده |
| المحطات والمدة و`paidUntil` | المبالغ والأقساط والمدفوعات ومراجعها |
| أسعار الجدول (معروضة في «أعلن معنا») | السعر المتفق عليه والملاحظات الداخلية |
